# 地區設定

傳回符合實體Local的字元字串。

```text
locale
```

## 備註

「本機」是定義區域設定的程式碼。 它由語言代碼，後接國家/地區代碼組成，以&#39;-&#39;分隔。 值的範例：

* en-US — 英文，美國
* en-GB — 英文、英國
* fr-FR — 法文、法國
* de-DE — 德文、德國
* es-ES — 西班牙文、西班牙
