# PushRelayInfo

可讓您將有關傳遞的資訊上傳到遠端追蹤伺服器。

```text
PushRelayInfo ( String instance, String dbId, XML document )
```

## 參數

**執行個體**&#x200B;執行個體名稱

**dbId**&#x200B;客戶資料庫識別碼

**檔案**&#x200B;包含資料的檔案

## 傳回值

無。
