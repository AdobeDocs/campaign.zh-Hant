# renameNode

變更元素或屬性的名稱。

```text
renameNode (node, namespaceURI, qualifiedName)
```

## 參數

**節點**&#x200B;元素/屬性型別節點。

**namespaceURI**&#x200B;新的名稱空間URI。

**qualifiedName**&#x200B;新限定名稱。

## 傳回值

已重新命名節點。 這可以是指定的節點，也可以是取代舊節點的節點。

## 功能

**類別的方法：** [DOMDocument](c-domdocument.md)

**可用於：**

* 內容管理
* 傳遞屬性
* 傳遞訊息
* 類型規則
* 匯入
* JSSP
* SOAP方法
* WebApp
* 工作流程
