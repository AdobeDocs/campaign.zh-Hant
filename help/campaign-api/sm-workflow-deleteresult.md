# DeleteResult

清除一或多個活動的結果。

```text
DeleteResult ( String workflowId, String activityName )
```

## 參數

**workflowId**&#x200B;工作流程的識別碼或內部名稱。

**activityName**&#x200B;您要清除其結果的活動名稱

## 傳回值

無。

## 功能

**結構描述：** [xtk:workflow](s-xtk-workflow.md)

**靜態：**

是
