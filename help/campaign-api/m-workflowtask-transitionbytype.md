# transitionByType

傳回與指定型別對應的轉變。

```text
transitionByType (type)
```

## 參數

**型別**&#x200B;轉換的型別。

## 傳回值

將型別作為引數傳遞的第一個轉變，如果活動沒有此型別的轉變，則為空。
