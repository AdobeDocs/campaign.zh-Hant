# 分派影像

告知應用程式伺服器傳送影像給中間來源伺服器。

```text
DispatchImages ( String images, Number providerId, String providerName )
```

## 參數

**影像**&#x200B;要上傳到中間來源伺服器的影像清單。

傳遞路由器的&#x200B;**providerId**&#x200B;識別碼。

**providerName**&#x200B;傳遞路由器的名稱。

## 傳回值

無。
