# AliasCleaning

使用清除後的分項清單來更新資料庫。

```text
AliasCleansing ( XML where, Date fromDate, Boolean refreshHit, Boolean resetHit )
```

## 參數

**其中**&#x200B;列舉篩選器。

**fromDate**&#x200B;調查回應的開始日期。

**refreshHit**&#x200B;點選更新。

**resetHit**&#x200B;點選更新是從開始的。

## 傳回值

無。
