# setFile

> 警告：
>
> 透過檔案API的存取權僅限於&#x200B;**var**、**sftp**&#x200B;和Adobe Campaign的暫存資料夾。

定義傳輸模式和接收檔案。

```text
setFile (filename)
```

## 參數

**檔案名稱**&#x200B;本機檔案的名稱。

## 傳回值

無。

## 功能

**類別的方法：** [FTP](c-ftp.md)

**可用於：**

* 內容管理
* 傳遞屬性
* 類型規則
* JSSP
* SOAP方法
* WebApp
* 工作流程
