# SysEnum

此控制項可讓您從系統分項清單中選擇值。

![SysEnum控制項](assets/sysenum.1eccf324.png)

## 屬性

**backColor — 字串**&#x200B;背景顏色（btnshadow，白色）。

**邊框 — 字串**&#x200B;變更控制項輪廓樣式（實線、雙線、內縮、外凸、無）。

**defaultIfInvalid — 如果值無效，則使用**&#x200B;字串。

**列舉 — 要使用的字串**&#x200B;列舉。

**font-size - integer**&#x200B;變更字型大小。

**標籤 — 字串**&#x200B;關聯的標籤。

**noInvalidErr — 布林值**&#x200B;如果值無效，則不會顯示錯誤。

**nolabel — 布林值**&#x200B;隱藏關聯的標籤。

**readOnly — 布林值**&#x200B;強制控制項為唯讀。

**必要 — 布林值**&#x200B;欄位是必要的。

**序列化 — 布林值**&#x200B;儲存最後選取的值。

**useDesc — 布林值**&#x200B;顯示說明，而非標籤。

**xpathEnum - xpath**&#x200B;使用這個XPath參考的值，而不是列舉的enum屬性。
