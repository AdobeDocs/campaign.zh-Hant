# sendError

使用作為引數傳遞的錯誤碼來傳回錯誤回應。

```text
sendError (errorCode)
```

## 參數

**errorCode** HTTP錯誤代碼。

## 傳回值

無。

## 功能

**類別的方法：** [HttpServletResponse](c-httpservletresponse.md)

**可用於：**

* JSSP
* WebApp
