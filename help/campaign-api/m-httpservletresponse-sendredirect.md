# sendRedirect

傳回暫時重新導向至其他URL。

```text
sendRedirect (location)
```

## 參數

**位置**&#x200B;重新導向URL。

## 傳回值

無。

## 功能

**類別的方法：** [HttpServletResponse](c-httpservletresponse.md)

**可用於：**

* JSSP
* WebApp
