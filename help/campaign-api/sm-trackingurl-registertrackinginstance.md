# RegisterTrackingInstance

核准重新導向伺服器上的追蹤執行個體 (透過設定資料庫識別碼)。

```text
RegisterTrackingInstance ( String serverUrl, String secureServerUrl, String serverUrlList, String instanceName, String cryptedPassword )
```

## 參數

**serverUrl**&#x200B;追蹤伺服器的外部URL

**secureServerUrl**&#x200B;追蹤伺服器的外部安全URL

**serverUrlList**&#x200B;追蹤伺服器的內部URL

要核准的執行個體的&#x200B;**instanceName**&#x200B;名稱

**cryptedPassword**&#x200B;加密密碼

## 傳回值

無。

## 功能

**結構描述：** [nms:trackingUrl](s-nms-trackingurl.md)

**靜態：**

是
