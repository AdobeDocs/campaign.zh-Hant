# 載入

將檔案的內容載入緩衝區。

```text
load (filename)
```

## 參數

**檔案名稱**&#x200B;要載入的檔案名稱。

## 傳回值

無。

## 功能

**類別的方法：** [MemoryBuffer](c-memorybuffer.md)

**可用於：**

* 內容管理
* 傳遞屬性
* 傳遞訊息
* 類型規則
* 匯入
* JSSP
* SOAP方法
* WebApp
* 工作流程
