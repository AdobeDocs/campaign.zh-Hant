# Cookie （類別）

代表由servlet和網頁瀏覽器交換的Cookie。

## 屬性

| 屬性 | 說明 |
| --- | --- |
| [名稱](p-cookie-name.md) | Cookie名稱。 |
| [註解](p-cookie-comment.md) | 說明Cookie函式的註解，若未定義，則為null。 |
| [網域](p-cookie-domain.md) | Cookie的網域名稱。 |
| [maxAge](p-cookie-maxage.md) | Cookie存留時間（以秒為單位）。 |
| [路徑](p-cookie-path.md) | 網頁瀏覽器轉送Cookie時所依據的路徑。 |
| [安全](p-cookie-secure.md) | 如果Cookie只能透過安全通訊協定轉送，則為true。 |
| [值](p-cookie-value.md) | Cookie值。 |
| [版本](p-cookie-version.md) | Cookie相容的通訊協定版本。 |

## 功能

**可用於：**

* JSSP
* WebApp
