# getFirstElement

透過驗證給定條件來傳回第一個子元素。

```text
getFirstElement (tagName [, attrName ] [, attrValue ])
```

## 參數

**tagName**&#x200B;搜尋專案的名稱。

**attrName**&#x200B;必須驗證指定值的屬性名稱。

**attrValue**&#x200B;屬性值。

## 傳回值

第一個元素會驗證指定的條件或Null。

## 功能

**類別的方法：** [DOMElement](c-domelement.md)

**可用於：**

* 內容管理
* 傳遞屬性
* 傳遞訊息
* 類型規則
* 匯入
* JSSP
* SOAP方法
* WebApp
* 工作流程
