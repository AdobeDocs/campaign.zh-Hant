# digestStrSha1

> 警告：
>
> 不得使用此函式根據個人資訊建立雜湊。

計算字元字串的SHA-1雜湊。 字串在計算之前會自動以UTF-8編碼。

```text
digestStrSha1 (string)
```

## 參數

**字串**&#x200B;要計算雜湊的字串。

## 傳回值

作為引數傳遞的字串的SHA-1雜湊。

## 功能

**可用於：**

* 內容管理
* 傳遞屬性
* 傳遞訊息
* 類型規則
* 匯入
* JSSP
* SOAP方法
* WebApp
* 工作流程
