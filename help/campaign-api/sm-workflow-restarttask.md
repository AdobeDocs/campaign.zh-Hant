# 重新啟動工作

強制重新啟動一或多個已完成的工作。

```text
RestartTask ( String workflowId, String activityName )
```

## 參數

**workflowId**&#x200B;工作流程的識別碼或內部名稱。

要重新啟動的&#x200B;**activityName**&#x200B;活動名稱

## 傳回值

無。
