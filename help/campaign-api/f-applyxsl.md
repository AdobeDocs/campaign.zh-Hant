# applyxsl

使用XSL樣式表轉換XML檔案。

```text
applyXsl (xslEntity, xml)
```

## 參數

**xslEntity**&#x200B;儲存在資料庫中的XSL樣式表名稱。

**xml**&#x200B;包含要轉換之XML檔案的XML檔案或字元字串。

## 傳回值

轉換後字元字串形式的XML檔案。

## 功能

**可用於：**

* 內容管理
* 傳遞屬性
* 類型規則
* JSSP
* SOAP方法
* WebApp
* 工作流程
