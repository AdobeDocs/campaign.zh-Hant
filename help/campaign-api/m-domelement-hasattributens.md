# hasAttributeNs

測試屬性的存在。

```text
hasAttributeNS (namespaceURI, localName)
```

## 參數

屬性名稱空間的&#x200B;**namespaceURI** URI。

**localName**&#x200B;屬性名稱。

## 傳回值

如果屬性存在，則為true ，否則為false。

## 功能

**類別的方法：** [DOMElement](c-domelement.md)

**可用於：**

* 內容管理
* 傳遞屬性
* 傳遞訊息
* 類型規則
* 匯入
* JSSP
* SOAP方法
* WebApp
* 工作流程
