# getRemoteAddr

傳回使用者端或上次傳送要求的Proxy的IP位址。

```text
getRemoteAddr ()
```

## 參數

無。

## 傳回值

包含傳送查詢之使用者端的IP位址的字串。

## 功能

**類別的方法：** [HttpServletRequest](c-httpservletrequest.md)

**可用於：**

* JSSP
* WebApp
