# 路徑編輯

控制項以選取欄位。

## 屬性

**backColor — 字串**&#x200B;背景顏色（btnshadow，白色）。

**邊框 — 字串**&#x200B;變更控制項輪廓樣式（實線、雙線、內縮、外凸、無）。

**font-size - integer**&#x200B;變更字型大小。

**hideCalculated — 布林值**&#x200B;隱藏計算欄位。

**hideMappedAsXml — 布林值**&#x200B;隱藏XML欄位。

**標籤 — 字串**&#x200B;關聯的標籤。

**nolabel — 布林值**&#x200B;隱藏關聯的標籤。

**noTransaction — 布林值**&#x200B;停用交易模式。

**readOnly — 布林值**&#x200B;強制控制項為唯讀。

**必要 — 布林值**&#x200B;欄位是必要的。

**useLink11Path — 布林值**&#x200B;顯示1:1連結。

**useTablePath — 布林值**&#x200B;顯示資料表。

**useUnboundPath — 布林值**&#x200B;顯示集合。

**xpath — 字串**&#x200B;要編輯的欄位。

**xpathBaseType - xpath**&#x200B;儲存所選欄位型別的路徑。

**xpathDataPolicy - xpath**&#x200B;儲存所選欄位的dataPolicy屬性的路徑。

**xpathEnum - xpath**&#x200B;儲存所選欄位之系統列舉的路徑。

**xpathLabel — 字串**&#x200B;儲存所選欄位標籤的路徑。

**xpathSchema — 字串**&#x200B;結構描述路徑。

**xpathSchemaMd5 - xpath**&#x200B;儲存結構描述MD5的路徑。

**xpathStartPath - startPath的字串**&#x200B;路徑（僅在定義xpathSchema時使用）。

**xpathUnbound - xpath**&#x200B;儲存所選欄位之未繫結屬性的路徑。

**xpathUserEnum - xpath**&#x200B;儲存所選欄位可用列舉的路徑。

**xpathType - xpath**&#x200B;儲存所選欄位預設控制項的路徑。

**縮放 — 布林值**&#x200B;顯示編輯按鈕。
