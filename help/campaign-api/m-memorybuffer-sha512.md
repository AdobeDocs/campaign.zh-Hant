# sha512

計算MemoryBuffer內容的SHA-2 512位元簽章。

```text
sha512 ()
```

## 參數

無。

## 傳回值

字元字串，即SHA-2 512位元簽章的十六進位表示。

## 功能

**類別的方法：** [MemoryBuffer](c-memorybuffer.md)

**可用於：**

* 內容管理
* 傳遞屬性
* 傳遞訊息
* 類型規則
* 匯入
* JSSP
* SOAP方法
* WebApp
* 工作流程
