# transitionByName

傳回與指定名稱對應的轉變。

```text
transitionByName (name)
```

## 參數

**名稱**&#x200B;轉換的名稱。

## 傳回值

名稱為的引數傳遞轉變，如果活動沒有此名稱的轉變，則為空值。
