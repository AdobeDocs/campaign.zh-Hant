# hasAttributes

測試節點是否至少具有一個屬性。

```text
hasAttributes ()
```

## 參數

無。

## 傳回值

如果節點有一或多個屬性，則為true，否則為false。

## 功能

**類別的方法：** [DOMNode](c-domnode.md)

**可用於：**

* 內容管理
* 傳遞屬性
* 傳遞訊息
* 類型規則
* 匯入
* JSSP
* SOAP方法
* WebApp
* 工作流程
