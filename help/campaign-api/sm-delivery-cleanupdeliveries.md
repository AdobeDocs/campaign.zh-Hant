# CleanupDeliveries

指定中間來源伺服器應該刪除某些傳遞。

```text
CleanupDeliveries ( String deliveryId )
```

## 參數

**deliveryId**&#x200B;傳送資料庫中的傳遞識別碼清單（以逗號分隔）

## 傳回值

無。
