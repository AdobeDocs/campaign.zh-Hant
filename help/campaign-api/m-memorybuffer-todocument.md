# toDocument

從此緩衝區的文字內容傳回XML檔案。

```text
toDocument ( [codePage ])
```

## 參數

**codePage**&#x200B;為所用字元頁編碼的整數。 預設為MemoryBuffer.CODEPAGE\_UTF8。

## 傳回值

[DOMDocument](c-domdocument.md)型別物件。

## 功能

**類別的方法：** [MemoryBuffer](c-memorybuffer.md)

**可用於：**

* 內容管理
* 傳遞屬性
* 傳遞訊息
* 類型規則
* 匯入
* JSSP
* SOAP方法
* WebApp
* 工作流程
