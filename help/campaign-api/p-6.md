# 使用XML

許多JavaScript API會將XML型別物件視為引數或傳回這些物件。 舊版Adobe Campaign已針對此使用JavaScript E4X擴充功能，可讓您以語言直接操控XML元素。 不過，這項技術正在慢慢地被放棄。

為了取代此技術，已新增新物件來操作XML檔案。 它們會以某些擴充功能恢復檔案物件模型(DOM)介面的子集。 符號物件也可用於輕鬆建立XML檔案，這是JXON BadgetFish慣例的簡化版本。

## DOM介面

[DOMDocument](c-domdocument.md)物件是XML檔案。 可以由字元字串、JXON物件或直接從檔案建立。 以下是建立DOM檔案的範例：

```javascript
var doc  = new DOMDocument("recipient")
var root = doc.root
root.setAttribute("id", 12345)
var firstName = doc.createElement("firstName")
firstName.textContent = "John"
root.appendChild(firstName)

logInfo(doc.toXMLString(true))
```

此介面與W3C規格有各種顯著差異：

* 函式getElements\*以及childNodes和屬性屬性會傳回JavaScript表格而非NodeList物件，因此允許使用表格自己的函式： forEach、map、...
* 若未指定值，某些屬性會傳回空字串，而不是null。

此外，也新增了某些公用程式函式和一些非標準擴充功能。 例如，若要讀取或修改屬性，只需寫入：

```javascript
aRecipient.$firstName
aRecipient.$firstName = "John"
```

而非：

```javascript
aRecipient.getAttribute("firstName")
aRecipient.setAttribute("firstName", "John")
```

使用$name屬性指派屬性時，可能會採用字串、布林值、日期或數字，而值會自動轉換為字元字串：

```javascript
aRecipient.$firstName = "John"
aRecipient.$lastModified = new Date()
aRecipient.$age = 35
aRecipient.$blocklist = false
```

## JXON

JXON是JavaScript物件的標籤法慣例，用於輕鬆建置XML檔案。 此標籤法不允許您建立所有可能的XML檔案。 例如，它不允許您指定與屬性同名的元素，而且不會管理名稱空間。 它適用於Adobe Campaign檔案。 如需更複雜的需求，您一律可以使用傳統DOM函式（依元素剖析或建立元素）。 XML物件由JavaScript物件表示，其屬性與元素和屬性相符。 值型別會決定它是與元素或屬性有關。

* 字串值為字元字串的屬性
* 布林值值為&#39;true&#39;或&#39;false&#39;的屬性
* 數字值是十進位數字表示的屬性
* Date其值是日期和時間的ISO-8601表示法的屬性
* 物件An元素
* 陣列A元素清單

$$名稱下的特殊屬性用於元素的文字內容範例：

> **JXON：**
>
> ```javascript
> { alice: { $: "bob" } }
> ```
>
> **XML：**
>
> ```xml
> <alice>bob</alice>
> ```
>
> **JXON：**
>
> ```javascript
> { alice: { 
>     bob: { $: "charlie" }, 
>     david: { $: "edgar" }
> }}
> ```
>
> **XML：**
>
> ```xml
> <alice>
>     <bob>charlie</bob>
>     <david>edgar</david>
> </alice>
> ```
>
> **JXON：**
>
> ```javascript
> { alice: { 
>     bob: [
>         { $: "charlie" }, 
>         { $: "david" } ]
> }}
> ```
>
> **XML：**
>
> ```xml
> <alice>
>     <bob>charlie</bob>
>     <bob>david</bob>
> </alice>
> ```
>
> **JXON：**
>
> ```javascript
> { alice: { 
>     charlie: "david",
>     $: "bob"
> }}
> ```
>
> **XML：**
>
> ```xml
>                             <alice charlie="david">bob</alice>
> ```
>
> **JXON：**
>
> ```javascript
> { recipient: {
>     firstName: "John",
>     id: 1234,
>     "creation-date": getCurrentDate(),
>     blocklist: false
> }}
> ```
>
> **XML：**
>
> ```xml
> <recipient
>     firstName="John"
>     id="1234"
>     creation-date="2013-04-19 10:58:22Z"
>     blocklist="false"/>
> ```

當屬性包含無效的JavaScript識別碼的特殊字元時，這些字元必須放在引號中。

```javascript
{ recipient: { "recipient-id" : 1234 }}
      
```

JXON物件可用於任何函式預期檔案或XML元素的引數中。 例如：

```javascript
var doc = DOMDocument.fromJXON({queryDef: 
    {schema: "xtk:workflow", operation: "select",
      select: { node: {expr: "@internalName"} } 
    }
  })
var query = NLWS.xtkQueryDef.create(doc)
```

相當於：

```javascript
var query = NLWS.xtkQueryDef.create({queryDef: 
    {schema: "xtk:workflow", operation: "select",
      select: { node: {expr: "@internalName"} } 
    }
  })
```

請務必注意，操作XML檔案是由DOM物件完成，JXON物件是僅用於初始化的公用程式。 從常值JavaScript結構建立XML檔案比較實用，尤其是當檔案包含可變零件時。
