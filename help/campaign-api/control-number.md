# 編號

此控制項可讓您輸入數字。

![號碼控制項](assets/number.d018cb51.png)

## 屬性

**backColor — 字串**&#x200B;背景顏色（btnshadow，白色）。

**邊框 — 字串**&#x200B;在控制項期間變更邊框樣式（實線、雙線、內縮、外凸、無）。

**digitCount - integer**&#x200B;逗號後面要顯示的數字數目。 預設值為2。

**font-size - integer**&#x200B;變更字型大小。

**標籤 — 字串**&#x200B;關聯的標籤。

**nolabel — 布林值**&#x200B;隱藏關聯的標籤。

**readOnly — 布林值**&#x200B;強制控制項為唯讀。

**必要 — 布林值**&#x200B;欄位是必要的。

**寬度 — integer**&#x200B;要顯示的字元數。 預設值為18，與000 000 000 000.00一致。
