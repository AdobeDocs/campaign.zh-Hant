# 列舉（類別）

代表分項清單的定義。

## 屬性

| 屬性 | 說明 |
| --- | --- |
| [baseType](p-enumeration-basetype.md) | 傳回提供列舉型別的字元字串。 |
| [預設](p-enumeration-default.md) | 傳回提供列舉預設值的字元字串。 |
| [描述](p-enumeration-description.md) | 傳回提供列舉說明的字元字串。 |
| [hasImage](p-enumeration-hasimage.md) | 傳回布林值，指出列舉是否有影像。 |
| [標籤](p-enumeration-label.md) | 傳回提供列舉標籤的字元字串。 |
| [名稱](p-enumeration-name.md) | 傳回提供列舉名稱的字元字串。 |
| [值](p-enumeration-values.md) | 傳回物件，其中每個屬性都是依其值編制索引的[EnumerationValue](c-enumerationvalue.md)物件。 |

## 功能

**可用於：**

* 內容管理
* 傳遞屬性
* 類型規則
* JSSP
* SOAP方法
* WebApp
* 工作流程
