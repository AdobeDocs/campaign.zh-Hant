# RecipientSubmit

為選定的收件者訂閱/取消訂閱資訊服務清單。

```text
XML confirmationIds = RecipientSubscribe ( XML recipientList, XML serviceList, Boolean subscribe, XML sendConfirmation )
```

## 參數

**recipientList**&#x200B;收件者清單

**serviceList**&#x200B;服務清單

**訂閱**&#x200B;訂閱/取消訂閱收件者

**sendConfirmation**&#x200B;傳送確認訊息

## 傳回值

**confirmationIds**&#x200B;確認識別碼清單
