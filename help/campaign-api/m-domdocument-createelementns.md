# createElementNs

使用指定的名稱和名稱空間建立新元素。

```text
createElementNS (namespaceURI, qualifiedName)
```

## 參數

**名稱空間URI**&#x200B;名稱空間URI。

**qualifiedName**&#x200B;要建立的專案的限定名稱。

## 傳回值

已建立[元素](c-domelement.md)。

## 功能

**類別的方法：** [DOMDocument](c-domdocument.md)

**可用於：**

* 內容管理
* 傳遞屬性
* 傳遞訊息
* 類型規則
* 匯入
* JSSP
* SOAP方法
* WebApp
* 工作流程
