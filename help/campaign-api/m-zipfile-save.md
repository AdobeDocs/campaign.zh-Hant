# 儲存

儲存封存。

```text
save ( [filename ] [, overwrite ])
```

## 參數

**檔案名稱**&#x200B;封存的名稱。 如果未指定名稱或名稱為空，則會以原始名稱儲存封存。

**覆寫**&#x200B;若為&#39;false&#39;，若已有此名稱的檔案存在，則不會儲存封存，且會引發例外狀況。

## 傳回值

無。

## 功能

**類別的方法：** [ZipFile](c-zipfile.md)

**可用於：**

* 內容管理
* 傳遞屬性
* 類型規則
* JSSP
* SOAP方法
* WebApp
* 工作流程
