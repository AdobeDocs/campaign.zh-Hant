# 指示頁面

包含函式或字串的程式庫。

## 語法

&lt;%@頁面匯入=&quot;lib1， ...&quot; %> &lt;%@頁面stringGroup=&quot;groupName&quot; %>

## 說明

匯入字串程式庫會顯示全域JavaScript物件，其名稱開頭為sg\_，後面接已使用&#39;\_&#39;取代特殊字元的程式庫名稱。 例如，納入nms:campaign將建立sg\_nms\_campaign變數。

## 範例

```xml
      <%@ page import="xtk:shared/nl.js,nms:campaign.js" %>
<%@ page stringGroup="nms:campaign" %>
...
<%= sg_nms_campaign.stateLabel() %>
...
```
