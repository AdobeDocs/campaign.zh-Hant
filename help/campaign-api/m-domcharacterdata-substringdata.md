# substringData

擷取部分文字。

```text
substringData (offset, count)
```

## 參數

**offset**&#x200B;第一個字元的位置（第一個字元為0）。

**count**&#x200B;要擷取的字元數。

## 傳回值

已擷取字元字串。

## 功能

**類別的方法：** [DOMCharacterData](c-domcharacterdata.md)

**可用於：**

* 內容管理
* 傳遞屬性
* 傳遞訊息
* 類型規則
* 匯入
* JSSP
* SOAP方法
* WebApp
* 工作流程
