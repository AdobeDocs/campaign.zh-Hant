# DOMAttr （類別）

屬性型別節點。

## 屬性

| 屬性 | 說明 |
| --- | --- |
| [isId](p-domattr-isid.md) | 如果屬性是ID型別，則為true。 |
| [名稱](p-domattr-name.md) | 屬性名稱。 |
| [ownerElement](p-domattr-ownerelement.md) | 具有此屬性或Null的元素。 |
| [已指定](p-domattr-specified.md) | 如果明確指定值，則為true （預設為不是隱含值）。 |
| [值](p-domattr-value.md) | 屬性文字值。 |

## 功能

**可用於：**

* 內容管理
* 傳遞屬性
* 傳遞訊息
* 類型規則
* 匯入
* JSSP
* SOAP方法
* WebApp
* 工作流程
