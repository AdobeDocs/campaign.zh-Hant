# appendChild

在子資料夾清單的結尾插入節點。

```text
appendChild (newChild)
```

## 參數

要插入的&#x200B;**newChild**&#x200B;節點。

## 傳回值

插入的節點。

## 功能

**類別的方法：** [DOMNode](c-domnode.md)

**可用於：**

* 內容管理
* 傳遞屬性
* 傳遞訊息
* 類型規則
* 匯入
* JSSP
* SOAP方法
* WebApp
* 工作流程
