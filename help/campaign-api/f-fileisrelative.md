# fileIsRelative

指定檔案名稱是否為相對名稱。

```text
fileIsRelative (fileName)
```

## 參數

**檔案名稱**&#x200B;檔案名稱。

## 傳回值

檔案名稱的True為相對。

## 功能

**可用於：**

* 內容管理
* 傳遞屬性
* 類型規則
* JSSP
* SOAP方法
* WebApp
* 工作流程
