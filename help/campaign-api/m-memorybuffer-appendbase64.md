# appendBase64

將資料從以base 64編碼的字元字串附加至緩衝區的結尾。

```text
appendBase64 (string)
```

## 參數

**字串**&#x200B;代表以base 64編碼的二進位資料，以新增至緩衝區的字元字串。

## 傳回值

無。
