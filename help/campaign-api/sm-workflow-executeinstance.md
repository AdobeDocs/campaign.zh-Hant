# Executinstance

立即執行工作流程並等待它完成。

```text
workflow.ExecuteInstance ( Boolean simulationMode, Boolean keepResult, Boolean logSQL )
```

## 參數

**simulationMode**&#x200B;執行模擬。

**keepResult**&#x200B;保留中期結果。

**logSQL**&#x200B;是否需要儲存SQL順序的追蹤？

## 傳回值

無。
