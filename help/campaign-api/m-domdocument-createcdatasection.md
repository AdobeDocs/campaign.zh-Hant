# createCDATASection

建立新的CDATA型別節點。

```text
createCDATASection (data)
```

## 參數

**資料**&#x200B;要插入CDATA節點的字元字串。

## 傳回值

已建立[CDATA節點](c-domcharacterdata.md)。
