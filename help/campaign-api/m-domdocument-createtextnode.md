# createTextNode

建立新的文字型別節點。

```text
createTextNode (data)
```

## 參數

**資料**&#x200B;要插入文位元組點的字元字串。

## 傳回值

[DOMCharacterData](c-domcharacterdata.md)型別節點已建立。

## 功能

**類別的方法：** [DOMDocument](c-domdocument.md)

**可用於：**

* 內容管理
* 傳遞屬性
* 傳遞訊息
* 類型規則
* 匯入
* JSSP
* SOAP方法
* WebApp
* 工作流程
