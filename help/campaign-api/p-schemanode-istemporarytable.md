# isTemporaryTable

傳回布林值，指出資料表是否為暫存資料表。 資料表不會在資料庫建立期間建立。

```text
isTemporaryTable
```

## 功能

類別的&#x200B;**屬性：** [SchemaNode](c-schemanode.md)

**唯讀：**

是

* 內容管理
* 傳遞屬性
* 類型規則
* JSSP
* SOAP方法
* WebApp
* 工作流程
