# 使用日期

本章詳細說明在伺服器上執行的JavaScript程式（工作流程、JSSP等）中用於操控日期的功能。

## 日期和時區

在JavaScript中，日期是以UTC儲存。 這表示您只需要擔心日期建構或轉換為文字字串以進行內部顯示或儲存的時區對於日期轉換，有兩種函式類別：

* JavaScript程式庫的函式(date.toString()、date.toLocaleString()、date.getHours()、...)，
* Adobe Campaign平台的功能( [formatDate(date， format)](f-formatdate.md) )。

根據慣例，第一次使用機器的時區，而最後一次使用時區取決於內容：通常是目前運運算元的時區，不過此行為可針對匯出或工作流程進行修改。

## 取得目前日期

在JavaScript中有兩種取得目前日期的方式：

* new Date()會建立以目前日期初始化的新Date物件。 日期與執行指令碼的電腦時間一致。
* [getCurrentDate()](f-getcurrentdate.md)會根據資料庫伺服器的時間傳回目前日期。

[getCurrentDate()](f-getcurrentdate.md)函式比第一個解決方案更適合，尤其是當要比較日期與資料庫中的其他日期，或是要寫入資料庫時。 此方法可減少因應用程式伺服器和資料庫伺服器之間的時間差異而產生的差異（最多幾分鐘）風險

## 日期顯示

將日期轉換為字元字串以進行顯示，會使用[formatDate](f-formatdate.md)函式。

## 從XML檔案轉換日期

儲存在來自Adobe Campaign資料庫之XML檔案中的日期為文字形式：可以使用[parseTimeStamp](f-parsetimestamp.md)函式來轉換這些日期。 這通常與[ExecuteQuery](sm-querydef-executequery.md)方法傳回的XML檔案有關。 範例：

```javascript
var query = NLWS.xtkQueryDef.create(
  {queryDef: {schema: "nms:delivery", operation: "get", 
    select: {
      node: {expr: "@lastModified"}
    }, 
    where: {
      condition: {expr: "@id=123456"}
    }
  }}
)

var delivery = query.ExecuteQuery()
var lastModified = parseTimeStamp(delivery.$lastModified)
```

## 在XML檔案中插入日期

若要以XML屬性寫入日期、儲存檔案（[Write](sm-session-write.md)方法），或是將常值日期插入查詢的運算式中，必須將該日期轉換為ISO8601格式。 xtk:shared/nl.js函式庫中有將日期轉換為此格式的方法：NL.XTK.formatDateTime(date)方法。 可使用loadLibrary函式載入程式庫：

```javascript
loadLibrary("xtk:shared/nl.js")
```

或在動態JavaScript頁面(JSSP)的情況下使用頁面指示詞：

```xml
<%@ page import="xtk:shared/nl.js" %>
```

警告：您無法對所有指令碼使用loadLibrary。 例如，您無法在電子郵件個人化指令碼中變更JavaScript功能的程式庫。 範例：此範例顯示使用常值日期來建構查詢。

```javascript
loadLibrary("xtk:shared/nl.js")
NL.require('/nl/core/shared/xtk.js')
...

var date = ...

var query = NLWS.xtkQueryDef.create(
  {queryDef: {schema: "nms:delivery", operation: "select", 
    select: {
      node: {expr: "@id"}
    }, 
    where: {
      condition: {expr: "@lastModified > #" + NL.XTK.formatDateTime(date) + "#"}
    }
  }})

var result = query.ExecuteQuery()
```
