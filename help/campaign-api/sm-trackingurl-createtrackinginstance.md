# CreateTrackingInstance

在重新導向伺服器上建立或設定追蹤執行個體

```text
CreateTrackingInstance ( String internalPwd, String serverUrl, String secureServerUrl, String serverUrlList, String instanceName, String cryptedPassword, String host )
```

## 參數

**internalPwd**&#x200B;內部密碼

**serverUrl**&#x200B;追蹤伺服器的外部URL

**secureServerUrl**&#x200B;追蹤伺服器的外部安全URL

**serverUrlList**&#x200B;追蹤伺服器的內部URL

要建立的執行個體的&#x200B;**instanceName**&#x200B;名稱

**cryptedPassword**&#x200B;加密密碼

與執行個體關聯的&#x200B;**主機** DNS遮罩

## 傳回值

無。

## 功能

**結構描述：** [nms:trackingUrl](s-nms-trackingurl.md)

**靜態：**

是
