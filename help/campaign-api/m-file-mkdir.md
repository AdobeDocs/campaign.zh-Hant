# mkdir

以目前[檔案](c-file.md)物件的路徑建立目錄。

```text
mkdir ()
```

## 參數

無。

## 傳回值

無。

## 備註

如有必要，也建立中繼目錄。 發生錯誤時會引發例外狀況。
