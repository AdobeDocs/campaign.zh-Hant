# createElement

建立新元素。

```text
createElement (tagName)
```

## 參數

**tagName**&#x200B;要建立的元素名稱。

## 傳回值

已建立[元素](c-domelement.md)。

## 功能

**類別的方法：** [DOMDocument](c-domdocument.md)

**可用於：**

* 內容管理
* 傳遞屬性
* 傳遞訊息
* 類型規則
* 匯入
* JSSP
* SOAP方法
* WebApp
* 工作流程
