# HttpServletResponse （類別）

代表傳回給使用者端的servlet回應。

此類別只有一個執行個體可由`response`變數存取。

## 方法

| 方法 | 說明 |
| --- | --- |
| [setContentType](m-httpservletresponse-setcontenttype.md) | 變更回應的檔案型別。 |
| [sendRedirect](m-httpservletresponse-sendredirect.md) | 傳回暫時重新導向至其他URL。 |
| [addCookie](m-httpservletresponse-addcookie.md) | 在回應中新增Cookie。 |
| [addHeader](m-httpservletresponse-addheader.md) | 在回應中新增其他HTTP標頭。 |
| [傳送錯誤](m-httpservletresponse-senderror.md) | 使用作為引數傳遞的錯誤碼來傳回錯誤回應。 |

## 功能

**可用於：**

* JSSP
* WebApp
