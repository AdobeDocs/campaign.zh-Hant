# GetAccessInfo

傳回匿名模式的繼承屬性。

```text
[ Boolean anonymous, Boolean parentAnonymous ] = GetAccessInfo ( Number categoryId )
```

## 參數

**categoryId**&#x200B;類別識別碼

## 傳回值

**匿名**&#x200B;指定類別優惠方案是否為匿名

**parentAnonymous**&#x200B;指定父類別優惠方案是否為匿名

## 功能

**結構描述：** [nms:offerCategory](s-nms-offercategory.md)

**靜態：**

是
