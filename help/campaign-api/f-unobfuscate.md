# 取消模糊化

藉由[模糊化](f-obfuscate.md)，將先前模糊化的整數取消模糊化。

```text
unobfuscate (value [, version ])
```

## 參數

**value**&#x200B;要模糊化的整數。

**版本**&#x200B;要套用的取消模糊化版本。 預設為0。

## 傳回值

先前被[模糊化](f-obfuscate.md)模糊化的整數。

## 功能

**可用於：**

* 內容管理
* 傳遞屬性
* 傳遞訊息
* 類型規則
* 匯入
* JSSP
* SOAP方法
* WebApp
* 工作流程
