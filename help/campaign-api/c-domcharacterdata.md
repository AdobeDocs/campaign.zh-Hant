# DOMCharacterData （類別）

僅包含文字的節點。 它可以是文字型別節點或註解。

## 方法

| 方法 | 說明 |
| --- | --- |
| [substringData](m-domcharacterdata-substringdata.md) | 擷取部分文字。 |
| [appendData](m-domcharacterdata-appenddata.md) | 新增字元字串至文字。 |
| [insertData](m-domcharacterdata-insertdata.md) | 將字元字串插入文字的特定位置。 |
| [deleteData](m-domcharacterdata-deletedata.md) | 刪除部分文字。 |
| [replaceData](m-domcharacterdata-replacedata.md) | 移除部分文字。 |

## 屬性

| 屬性 | 說明 |
| --- | --- |
| [資料](p-domcharacterdata-data.md) | 節點的文字值。 |
| [長度](p-domcharacterdata-length.md) | 節點中的字元數。 |

## 功能

**可用於：**

* 內容管理
* 傳遞屬性
* 傳遞訊息
* 類型規則
* 匯入
* JSSP
* SOAP方法
* WebApp
* 工作流程
