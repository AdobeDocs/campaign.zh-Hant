xml檔案。

## 方法

| 方法 | 說明 |
| --- | --- |
| [DOMDocument](m-domdocument-domdocument.md) | 建立新檔案。 |
| [fromXMLString](m-domdocument-fromxmlstring.md) | 從XML字元字串建立新檔案。 |
| [fromJXON](m-domdocument-fromjxon.md) | 從JXON物件建立新檔案。 |
| [載入](m-domdocument-load.md) | 從XML檔案建立新檔案。 |
| [toXMLString](m-domdocument-toxmlstring.md) | 將XML檔案轉換為字元字串。 |
| [createElement](m-domdocument-createelement.md) | 建立新元素。 |
| [createElementNS](m-domdocument-createelementns.md) | 使用指定的名稱和名稱空間建立新元素。 |
| [createTextNode](m-domdocument-createtextnode.md) | 建立新的文字型別節點。 |
| [createComment](m-domdocument-createcomment.md) | 建立新的註解型別節點。 |
| [createCDATASection](m-domdocument-createcdatasection.md) | 建立新的CDATA型別節點。 |
| [createProcessingInstruction](m-domdocument-createprocessinginstruction.md) | 建立新的處理指示。 |
| [createEntityReference](m-domdocument-createentityreference.md) | 建立新圖元參照。 |
| [getElementsByTagName](m-domdocument-getelementsbytagname.md) | 傳回具有指定名稱的所有元素清單。 |
| [getElementsByTagNameNS](m-domdocument-getelementsbytagnamens.md) | 傳回具有指定名稱和名稱空間的所有檔案元素清單。 |
| [getElementById](m-domdocument-getelementbyid.md) | 傳回具有指定ID的元素。 |
| [importNode](m-domdocument-importnode.md) | 從另一份檔案建立節點副本。 |
| [normalizeDocument](m-domdocument-normalizedocument.md) | 標準化檔案：取代圖元參照，並融合相鄰的文位元組點。 |
| [renameNode](m-domdocument-renamenode.md) | 變更元素或屬性的名稱。 |
