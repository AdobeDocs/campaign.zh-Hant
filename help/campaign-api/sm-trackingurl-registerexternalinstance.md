# RegisterExternalInstance

為重新導向伺服器核准轉送伺服器上的追蹤執行個體 (透過設定資料庫識別碼)。

```text
RegisterExternalInstance ( String login, String instanceName, String dbId, Boolean saveParams )
```

## 參數

**登入**&#x200B;轉送伺服器存取登入

要核准的執行個體的&#x200B;**instanceName**&#x200B;名稱

執行傳遞之客戶的&#x200B;**dbId**&#x200B;資料庫識別碼

**saveParams**&#x200B;儲存選項（如果成功）

## 傳回值

無。

## 功能

**結構描述：** [nms:trackingUrl](s-nms-trackingurl.md)

**靜態：**

是
