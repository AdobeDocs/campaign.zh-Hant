# toString

傳回字元字串形式的[MemoryBuffer](c-memorybuffer.md)的內容。

```text
toString ( [codePage ])
```

## 參數

**codePage**&#x200B;為所用字元頁編碼的整數。 預設為MemoryBuffer.CODEPAGE\_UTF8。

## 傳回值

以字元字串形式表示的印章內容。

## 功能

**類別的方法：** [MemoryBuffer](c-memorybuffer.md)

**可用於：**

* 內容管理
* 傳遞屬性
* 傳遞訊息
* 類型規則
* 匯入
* JSSP
* SOAP方法
* WebApp
* 工作流程
