# 檔案編輯

此控制項可讓您輸入檔案名稱。

![FileEdit控制項](assets/fileedit.56228d2a.png)

## 屬性

**backColor — 字串**&#x200B;背景顏色（btnshasow，白色）。

**邊框 — 字串**&#x200B;在控制項期間變更邊框樣式（實線、雙線、內縮、外凸、無）。

**dlgType — 字串**&#x200B;檔案選取視窗的型別（儲存、opendir、savedir）。

**篩選器 — 字串**&#x200B;篩選器清單

**font-size - integer**&#x200B;變更字型大小。

**標籤 — 字串**&#x200B;關聯的標籤。

**lastPath — 字串**&#x200B;檔案選取視窗的路徑。

**loadContent — 布林值**&#x200B;載入檔案的內容。

**nolabel — 布林值**&#x200B;隱藏關聯的標籤。

**readOnly — 布林值**&#x200B;強制控制項為唯讀。

**必要 — 布林值**&#x200B;欄位是必要的。

**標題 — 字串**&#x200B;選取範圍視窗的標題

**xpathCopyName - xpath**&#x200B;用來儲存檔案名稱的路徑（副檔名為）。

**xpathType - xpath**&#x200B;檔案型別（文字或XML）
