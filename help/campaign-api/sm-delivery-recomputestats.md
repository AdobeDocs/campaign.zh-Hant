# 重新計算統計資料

重新計算傳遞動作的傳遞和追蹤統計資料。

```text
RecomputeStats ( Number deliveryId, Number dirtyFlags )
```

## 參數

**deliveryId**&#x200B;傳遞識別碼

**dirtyFlags**&#x200B;位元欄位，說明要重新計算的專案（請參閱「nms:delivery:dirtyFlags」列舉）。

## 傳回值

無。

## 功能

**結構描述：** [nms:delivery](s-nms-delivery.md)

**靜態：**

是
