# CreateFromModel

從範本 (根據其內部名稱) 建立傳遞。

```text
XML delivery = CreateFromModel ( String scenarioName, XML content )
```

## 參數

**scenarioName**&#x200B;傳遞範本的內部名稱

要新增至範本的&#x200B;**內容** XML內容

## 傳回值

**傳遞**&#x200B;傳回建立的傳遞檔案

## 功能

**結構描述：** [nms:delivery](s-nms-delivery.md)

**靜態：**

是
