# HttpSoapConnection （類別）

代表與SOAP伺服器的HTTP連線。

## 方法

| 方法 | 說明 |
| --- | --- |
| [HttpSoapConnection](m-httpsoapconnection-httpsoapconnection.md) | 建立與SOAP伺服器的HTTP連線。 |
| [addHeader](m-httpsoapconnection-addheader.md) | 新增HTTP標頭 |
| [處置](m-httpsoapconnection-dispose.md) | 釋放物件使用的資源。 |
| [setHeader](m-httpsoapconnection-setheader.md) | 指定HTTP標頭。 |

* 傳遞屬性

* 匯入

* SOAP方法
