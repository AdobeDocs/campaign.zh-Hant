# NormalizationField

```text
NormalizeField ( XML selectedWebApp, XML archivedField, String newSQLName, String tableName, String schemaId, Boolean rename )
```

## 參數

**selectedWebApp**&#x200B;可以包含要正規化的欄位的調查問卷清單。

要正規化的欄位上的&#x200B;**archivedField**&#x200B;資訊。

**newSQLName**&#x200B;此欄位的新SQL名稱。

**tableName**&#x200B;將包含新SQL欄位的資料表名稱。

**schemaId**&#x200B;要新增屬於新欄位之參照的結構描述識別碼（檢視） （選擇性）。

**重新命名**&#x200B;同時重新命名先前標準化的欄位。

## 傳回值

無。

是
