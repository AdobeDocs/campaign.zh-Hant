# 衝突

> 警告：此函式適用於內部部署環境。

衝突實體的暫時儲存區。

## 方法

| 方法 | 說明 |
| --- | --- |
| [AcceptCus](sm-conflict-acceptcus.md) | 保留目前版本。 |
| [AcceptNew](sm-conflict-acceptnew.md) | 接受新版本為目前版本。 |
| [SetResolved](sm-conflict-setresolved.md) | 宣告實體不再有衝突。 |

## 泛型方法

| 方法 | 說明 |
| --- | --- |
| [建立](f-create.md) | 建立與指定結構描述對應的新實體。 |
| [載入](f-load.md) | 載入並傳回與指定結構描述和索引鍵對應的實體。 |
| [儲存](m-entity-save.md) | 將實體儲存在資料庫中。 |
