# isDefaultNamespace

測試指定的名稱空間是否為預設值。

```text
isDefaultNamespace (namespaceURI)
```

## 參數

**名稱空間URI**&#x200B;名稱空間URI。

## 傳回值

如果namespaceURI是預設名稱空間，則為true ，否則為false。

## 功能

**類別的方法：** [DOMNode](c-domnode.md)

**可用於：**

* 內容管理
* 傳遞屬性
* 傳遞訊息
* 類型規則
* 匯入
* JSSP
* SOAP方法
* WebApp
* 工作流程
