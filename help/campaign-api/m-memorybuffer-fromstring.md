# fromString

在緩衝區中載入字元字串的內容。

```text
fromString (string [, codepage ])
```

## 參數

**字串**&#x200B;字元字串。

**程式碼頁**&#x200B;用來序列化緩衝區中的字串的程式碼頁。 此選用引數可讓您指定字元編碼。 例如：

* iso-8859-1
* utf-8
* utf-16
* us-ascii
* shift-jis
* euc-kr

## 傳回值

無。

## 功能

**類別的方法：** [MemoryBuffer](c-memorybuffer.md)

**可用於：**

* 內容管理
* 傳遞屬性
* 傳遞訊息
* 類型規則
* 匯入
* JSSP
* SOAP方法
* WebApp
* 工作流程
