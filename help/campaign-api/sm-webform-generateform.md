# Generateform

以郵件或網頁模式產生表單

```text
String result = GenerateForm ( String formName, Boolean mailMode )
```

## 參數

**formName**&#x200B;表單名稱

**mailMode**&#x200B;產生郵件型別的表單

## 傳回值

**結果**&#x200B;表單上應用XSL的結果

## 功能

**結構描述：** [nms:webForm](s-nms-webform.md)

是
