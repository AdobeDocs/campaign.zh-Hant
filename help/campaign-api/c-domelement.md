# DOMElement （類別）

元素型別節點。

## 方法

| 方法 | 說明 |
| --- | --- |
| [toXMLString](m-domelement-toxmlstring.md) | 將元素轉換為字元字串。 |
| [getFirstElement](m-domelement-getfirstelement.md) | 透過驗證給定條件來傳回第一個子元素。 |
| [hasElement](m-domelement-haselement.md) | 透過驗證給定的准則來測試元素是否有子元素。 |
| [getValue](m-domelement-getvalue.md) | 傳回給定XPath參考的節點值。 |
| [getBooleanValue](m-domelement-getbooleanvalue.md) | 傳回給定XPath所參考的布林節點值。 |
| [getDateValue](m-domelement-getdatevalue.md) | 傳回指定XPath所參考之節點的日期+小時型別值。 |
| [getNumberValue](m-domelement-getnumbervalue.md) | 傳回給定XPath參考的數位節點值。 |
| [getElements](m-domelement-getelements.md) | 傳回屬於此元素的具有指定名稱的子元素清單。 |
| [getAttribute](m-domelement-getattribute.md) | 傳回屬性值。 |
| [setAttribute](m-domelement-setattribute.md) | 變更屬性的值或建立新屬性。 |
| [removeAttribute](m-domelement-removeattribute.md) | 刪除屬性。 |
| [getElementsByTagName](m-domelement-getelementsbytagname.md) | 傳回具有指定名稱的所有子元素清單。 |
| [getAttributeNS](m-domelement-getattributens.md) | 傳回屬性值。 |
| [setAttributeNS](m-domelement-setattributens.md) | 變更屬性的值或建立新屬性。 |
| [removeAttributeNS](m-domelement-removeattributens.md) | 刪除屬性。 |
| [getElementsByTagNameNS](m-domelement-getelementsbytagnamens.md) | 傳回具有指定名稱的所有子元素清單。 |
| [hasAttribute](m-domelement-hasattribute.md) | 測試屬性的存在。 |
| [hasAttributeNS](m-domelement-hasattributens.md) | 測試屬性的存在。 |
| [setIdAttribute](m-domelement-setidattribute.md) | 將指定的屬性宣告為ID型別屬性。 |
| [setIdAttributeNS](m-domelement-setidattributens.md) | 將指定的屬性宣告為ID型別屬性。 |

## 屬性
