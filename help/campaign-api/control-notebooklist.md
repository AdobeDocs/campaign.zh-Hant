# 筆記本清單

以索引標籤的形式顯示及編輯集合。

![NotebookList控制項](assets/notebooklist.688e32b9.png)

## 屬性

**backColor — 字串**&#x200B;背景顏色（btnshadow，白色）。

**名稱 — 字串**&#x200B;容器識別碼。

**noToolbar — 布林值**&#x200B;隱藏工具列。

**左內邊距 — 整數**&#x200B;容器左邊的空間（畫素）。

**右內距 — 整數**&#x200B;容器右側的空格（以畫素為單位）。

**padding-top — 容器上方的整數**&#x200B;空間（畫素）。

**下內邊距 — 整數**&#x200B;容器下方的空間（以畫素為單位）。

**內距 — 容器周圍的整數**&#x200B;畫素。

**readOnly — 布林值**&#x200B;強制控制項及其所有子系為唯讀。

**toobarAlign — 字串**&#x200B;水準\|垂直。

**toobarCaption — 工具列中顯示**&#x200B;標籤。

**xpath-label — 字串**&#x200B;提供索引標籤文字的路徑。
