| 方法 | 說明 |

| [取消](sm-localorder-cancel.md) | 取消訂單。 |
| [CreateFromCatalog](sm-localorder-createfromcatalog.md) | 從套件建立訂單。 |
| [EvaluateContent](sm-localorder-evaluatecontent.md) | 評估連結至訂單的傳遞內容。 這項評估將在使用操作員許可權訂購時以及建立本機行銷活動之前執行。 |
| [EvaluateContentFromId](sm-localorder-evaluatecontentfromid.md) | 評估連結至訂單的傳遞內容。 這項評估將在使用操作員許可權訂購時以及建立本機行銷活動之前執行。 |

| [EvaluateTargetFromId](sm-localorder-evaluatetargetfromid.md) | 評估連結至訂單的每個行銷活動傳遞的行銷活動目標定位。 這項評估將在使用操作員許可權訂購時以及建立本機行銷活動之前執行。 |
| [ExecuteTarget](sm-localorder-executetarget.md) | 執行連結至訂單的行銷活動目標選擇。 |

| [驗證](sm-localorder-validation.md) | 核准訂單。 |
