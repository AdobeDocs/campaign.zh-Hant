# toXMLString

將XML檔案轉換為字元字串。

```text
toXMLString (format)
```

## 參數

**format**&#x200B;要格式化XML檔案的布林值。

## 傳回值

無。

## 備註

此方法會新增prolog，不同於對有關元素具有相同名稱的方法。

## 功能

**類別的方法：** [DOMDocument](c-domdocument.md)

**可用於：**

* 內容管理
* 傳遞屬性
* 傳遞訊息
* 類型規則
* 匯入
* JSSP
* SOAP方法
* WebApp
* 工作流程
