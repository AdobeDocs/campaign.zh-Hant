# replaceChild

取代節點。

```text
replaceChild (newChild, oldChild)
```

## 參數

要插入的&#x200B;**newChild**&#x200B;節點。

要取代的&#x200B;**oldChild**&#x200B;節點。

## 傳回值

已取代節點。
