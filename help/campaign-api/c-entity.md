# 實體（類別）

代表指定之結構描述的資料庫實體。

此類物件無法直接具現化。 您必須使用create()、get()或load()方法。

## 方法

| 方法 | 說明 |
| --- | --- |
| [儲存](m-entity-save.md) | 將實體儲存在資料庫中。 |

## 功能

**可用於：**

* 內容管理
* 傳遞屬性
* 類型規則
* JSSP
* SOAP方法
* WebApp
* 工作流程
