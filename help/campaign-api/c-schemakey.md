# SchemaKey （類別）

代表索引鍵的定義。

## 屬性

| 屬性 | 說明 |
| --- | --- |
| [標籤](p-schemakey-label.md) | 傳回索引鍵的簡短說明。 |
| [描述](p-schemakey-description.md) | 傳回索引鍵的說明。 |
| [名稱](p-schemakey-name.md) | 傳回金鑰的識別碼。 |
| [isInternal](p-schemakey-isinternal.md) | 如果索引鍵是內部索引鍵，則傳回true。 |
| [allowEmptyPart](p-schemakey-allowemptypart.md) | 如果索引鍵的欄位可為空白（必須至少輸入其中一個欄位），則傳回true。 |
| [欄位](p-schemakey-fields.md) | 傳回包含索引鍵欄位( [SchemaNode](c-schemanode.md) )的資料表。 |

## 功能

**可用於：**

* 內容管理
* 傳遞屬性
* 類型規則
* JSSP
* SOAP方法
* WebApp
* 工作流程
