# toXMLString

將元素轉換為字元字串。

```text
toXMLString (format)
```

## 參數

**format**&#x200B;要格式化XML檔案的布林值。

## 傳回值

無。

## 功能

**類別的方法：** [DOMElement](c-domelement.md)

**可用於：**

* 內容管理
* 傳遞屬性
* 傳遞訊息
* 類型規則
* 匯入
* JSSP
* SOAP方法
* WebApp
* 工作流程
