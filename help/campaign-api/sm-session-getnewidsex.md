# GetNewIdsEx

在給定序列名稱的情況下，從資料庫中取得唯一識別碼的清單。

```text
String idList = GetNewIdsEx ( Number count, String sequence )
```

## 參數

**count**&#x200B;此方法應傳回的識別碼數目

**序列**&#x200B;要遞增的序列名稱

## 傳回值

**idList**&#x200B;以逗號分隔的識別碼清單
