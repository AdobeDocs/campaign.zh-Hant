# logVerbose

將資訊訊息新增至工作流程例項的記錄中。 此訊息僅在「詳細」模式下可見。

```text
logVerbose (message)
```

## 參數

**訊息**&#x200B;要新增至記錄檔的訊息。

## 傳回值

無。

## 功能

**可用於：**

* 內容管理
* 傳遞屬性
* 傳遞訊息
* 類型規則
* 匯入
* JSSP
* SOAP方法
* WebApp
* 工作流程
