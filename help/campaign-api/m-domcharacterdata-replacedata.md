# replaceData

移除部分文字。

```text
replaceData (offset, count, arg)
```

## 參數

**offset**&#x200B;要刪除的第一個字元位置（第一個字元為0）。

**count**&#x200B;要刪除的字元數。

**arg**&#x200B;要插入的字元字串。

## 傳回值

無。

## 功能

**類別的方法：** [DOMCharacterData](c-domcharacterdata.md)

**可用於：**

* 內容管理
* 傳遞屬性
* 傳遞訊息
* 類型規則
* 匯入
* JSSP
* SOAP方法
* WebApp
* 工作流程
