# setAttributeNs

變更屬性的值或建立新屬性。

```text
setAttributeNS (namespaceURI, qualifiedName, value)
```

## 參數

屬性名稱空間的&#x200B;**namespaceURI** URI。

**qualifiedName**&#x200B;屬性的限定名稱。

**值**&#x200B;屬性文字值。

## 傳回值

無。

## 功能

**類別的方法：** [DOMElement](c-domelement.md)

**可用於：**

* 內容管理
* 傳遞屬性
* 傳遞訊息
* 類型規則
* 匯入
* JSSP
* SOAP方法
* WebApp
* 工作流程
