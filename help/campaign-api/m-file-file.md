# 檔案

建立與檔案關聯的新物件。

```text
File (filename)
```

## 參數

**檔案名稱**&#x200B;要讀取或建立的檔案名稱。

## 傳回值

無。

## 備註

範例：

```javascript
var f = new File("/tmp/file.txt")
```

## 功能

**類別的方法：** [檔案](c-file.md)

**可用於：**

* 內容管理
* 傳遞屬性
* 類型規則
* JSSP
* SOAP方法
* WebApp
* 工作流程
