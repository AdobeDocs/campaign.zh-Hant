# E4X移轉指南

Mozilla已逐步捨棄在JavaScript中原生支援XML的E4X擴充功能。 Adobe Campaign大量使用此擴充功能，因此正準備移轉至替代解決方案。

本指南旨在說明替代解決方案，協助您遷移現有設定或開發新設定。

新舊系統並存，目前版本的Adobe Campaign一律與E4X相容，但新設定不得與E4X擴充功能一起開發。

提醒： E4X新增了可直接從來源程式建置的JavaScript xml型別：

```text
var doc = <xml> ... </xml>
```

或來自字串：

```text
var doc = new XML ("<xml>...</xml>")
```

然後可以使用特定API來操作：

```text
element.@id element.where
```

## XML型別

原生「xml」型別已由DOM API取代，這些是[DOMDocument](c-domdocument.md)、[DOMElement](c-domelement.md)、[DOMNode](c-domnode.md)型別……下列是最常見的等同作業：

> **E4X：**
>
> ```javascript
> anElement.@id
> ```
>
> **DOM：**
>
> ```javascript
> anElement.$id
> ```
>
> **E4X：**
>
> ```javascript
> anElement.@["recipient-id"]
> ```
>
> **DOM：**
>
> ```javascript
> anElement["$recipient-id"]
> ```
>
> **E4X：**
>
> ```javascript
> anElement.childElement
> ```
>
> **DOM：**
>
> ```javascript
> anElement.getElements("childElement")
> ```
>
> 或
>
> ```javascript
> anElement.getFirstElement("childElement")
> ```

必須取代JavaScript中的XML檔案。 當此檔案用於原生函式或SOAP呼叫，在引數中傳遞XML檔案時，您可以直接傳遞JXON。 這會自動轉換為XML檔案(DOMDocument)。 如果沒有，您可以一律透過JXON物件傳遞，但必須使用[DOMDocument.fromJXON](m-domdocument-fromjxon.md)函式進行明確轉換。

```javascript
var doc = DOMDocument.fromJXON({queryDef: 
{schema: "xtk:workflow", operation: "select",
  select: { node: {expr: "@internalName"} } 
}
})
```

XML和JXON語法之間的等同範例：

> **E4X：**
>
> ```xml
>                             <queryDef schema="nms:delivery" operation="get">
>     <select>
>         <node expr="@created"/>
>         <node expr="@lastModified"/>
>     </select>
>     <where>
>         <condition expr="@id=123456"/>
>     </where>
> </queryDef>
> ```
>
> **JXON：**
>
> ```javascript
>                             {queryDef: {schema: "nms:delivery", operation: "get", 
>     select: {
>         node: [
>             {expr: "@created"}, 
>             {expr: "@lastModified"}]
>         }, 
>     where: {
>         condition: {expr: "@id=123456"}
>     }
> }}
> ```

如需JXON語法的詳細資訊，請參閱使用XML頁面。

## SOAP呼叫

這些SOAP方法必須執行NLWS物件屬性。 結構描述的JavaScript ID是從名稱空間和以大寫開頭的名稱建立的。 例如，nms:delivery結構描述會以nmsDelivery作為其JS ID。

> **舊：**
>
> ```javascript
> nms.delivery.Play(deliveryId);
> ```
>
> **新增：**
>
> ```javascript
> NLWS.nmsDelivery.Play(deliveryId);
> ```

## SOAP JavaScript方法

若要接收其引數為DOM格式而非E4X格式的XML檔案，必須將dom=&quot;true&quot;屬性新增至結構描述中。

## 多行字串

使用XML建立多行字串必須取代為串連字串，因為忘記新增\\n行的結尾。

> **舊：**
>
> ```xml
> <str>line 1
> line 2
> line 3
> </str>.toString()
> ```
>
> **新增：**
>
> ```javascript
> "line 1\n" +
> "line 2\n" +
> "line 3\n"
> ```

## 內容管理

在預覽期間，必須在發佈範本上或JavaScript範本啟動DOM選項。 對於具有JavaScript前置處理的XSL轉換，您也必須啟用DOM選項（彙總器視窗）。

function isDOM()

}
