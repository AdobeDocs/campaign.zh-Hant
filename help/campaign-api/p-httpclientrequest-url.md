# URL

遠端伺服器的位址。

```text
url
```

## 備註

處於讀取/寫入模式的屬性。 範例：

```javascript
var http = new HttpClientRequest()
http.url = "http://www.adobe.net"
```

## 功能

類別的&#x200B;**屬性：** [HttpClientRequest](c-httpclientrequest.md)

**唯讀：**

否

* 內容管理
* 傳遞屬性
* 類型規則
* JSSP
* SOAP方法
* WebApp
* 工作流程
