# JavaScript例外狀況

根據預設，當錯誤發生時，執行的指令碼會中斷。 但是，4.05版以後的確可以讓您擷取錯誤並加以處理，以繼續處理指令碼。

Adobe Campaign引發的例外狀況是錯誤碼（ `Number`型別）。

## 範例

此範例嘗試從無效的位址復原網頁，並從[getUrl()](f-geturl.md)函式引發例外狀況。

```javascript
try
{
  var url = "xx:/invalid-url"
  getUrl(url)
}
catch(e)
{
  logInfo("Can't get page content: " + url )
  logInfo("Error number: " + e )
}

  
```
