# formatDate

將日期格式化為字元字串。

```text
formatDate (date, format [, timeZone ])
```

## 參數

**日期**&#x200B;轉換的日期。

**format**&#x200B;描述要使用的格式的字元字串。 用來格式化日期不同部分的字元如下：

* Y — 年
* M — 月份(1-12)
* B — 月份名稱
* D — 當月日期(1-31)
* A — 日名稱
* J — 一年當中的第幾天(1-366)
* W — 一年當中的第幾週
* H — 小時(0-23)
* I — 小時(1-12)
* N — 分鐘(0-59)
* S — 秒(0-59)
* P — 上午/下午

您可以在這些字元前面指定一個數字。 A和B字元後面可以有l字元來使用全名，而不是縮寫的版本，或是i字元來使用英文的名稱。 範例：

* 「%4Y/%2M/%2D」=> 2000/01/24。
* 「%A %D %B %4Y」=> 2000年1月24日星期一。
* 「%Al %D %Bl %4Y」=> 2000年1月24日星期一。
* 「%02H：%02N：%02S」會顯示小時、分和秒的數字。

**時區**&#x200B;與時區對應的字元字串。 xtk:common:時區列舉結構描述中指定了可能的值。

## 傳回值

以要求的格式表示日期的字元字串。
