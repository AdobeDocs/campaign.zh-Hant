# EnumerationValue （類別）

代表列舉值的定義。

## 屬性

| 屬性 | 說明 |
| --- | --- |
| [標籤](p-enumerationvalue-label.md) | 傳回提供目前列舉值的簡短說明的字元字串。 |
| [描述](p-enumerationvalue-description.md) | 傳回提供目前列舉值說明的字元字串。 |
| [值](p-enumerationvalue-value.md) | 傳回提供目前列舉值值的字元字串。 |
| [名稱](p-enumerationvalue-name.md) | 傳回提供目前列舉值名稱的字元字串。 |
| [影像](p-enumerationvalue-image.md) | 傳回字元字串，提供目前分項清單值的影像名稱。 |
| [enabledIf](p-enumerationvalue-enabledif.md) | 傳回字元字串，提供目前列舉值的有效性條件。 |

## 功能

**可用於：**

* 內容管理
* 傳遞屬性
* 類型規則
* JSSP
* SOAP方法
* WebApp
* 工作流程
