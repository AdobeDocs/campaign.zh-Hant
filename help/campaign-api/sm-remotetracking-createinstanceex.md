# CreateInstanceEx

用於建立追蹤執行個體

```text
CreateInstanceEx ( String instanceName, String hosts, String dbId, String cryptedPwd, String lang, String imsOrgId )
```

## 參數

要建立的執行個體的&#x200B;**instanceName**&#x200B;名稱

**主機**&#x200B;與執行個體關聯的DNS遮罩

執行傳遞之客戶的&#x200B;**dbId**&#x200B;資料庫識別碼

**cryptedPwd**&#x200B;用於追蹤的加密密碼

**lang**&#x200B;執行個體語言

**imsOrgId** IMS組織ID

## 傳回值

無。
