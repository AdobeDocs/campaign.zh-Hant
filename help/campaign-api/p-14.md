# 範例

## 靜態方法

在代表結構描述的物件上叫用方法即可存取SOAP方法。 結構描述是&#39;NLWS&#39;全域物件。 下列範例會叫用[xtk:workflow](s-xtk-workflow.md)結構描述的[PostEvent](sm-workflow-postevent.md)靜態方法。

```javascript
      NLWS.xtkWorkflow.PostEvent("WKF1", "signal", "", {variables: {foo: 'bar'}}, false)
    
```

## 非靜態方法

若要使用非靜態SOAP方法，您必須先使用對應結構描述上的[載入](f-load.md)或[建立](f-create.md)方法來復原實體。 下列範例會叫用[xtk:queryDef](s-xtk-querydef.md)結構描述的[ExecuteQuery](sm-querydef-executequery.md)方法。

```javascript
var query = NLWS.xtkQueryDef.create(
  {queryDef: {schema: "xtk:workflow", operation: "select", 
    select: {
      node: {expr: "@internalName"}
    }, 
    where: {
      condition: {expr: "[folder/@name]='wfExamples'"}
    }, 
    orderBy: {
      node: {expr: "@internalName", sortDesc: "false"}
    }
  }})

var res = query.ExecuteQuery()

for each (var w in res.getElements("workflow"))
  logInfo(w.$internalName)
    
```

## 限制

無法使用某些非靜態呼叫，因為正在載入的物件(\*\*)缺少資料。 例如，[nms:delivery](s-nms-delivery.md)上的某些呼叫就是這種情況。
