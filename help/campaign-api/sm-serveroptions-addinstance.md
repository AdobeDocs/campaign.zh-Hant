# AddInstance

> 警告：此函式適用於內部部署環境。

在伺服器上宣告新執行個體

```text
AddInstance ( String instanceName, String hosts, String lang )
```

## 參數

要建立的執行個體的&#x200B;**instanceName**&#x200B;名稱

**主機**&#x200B;與執行個體關聯的DNS遮罩

**lang**&#x200B;執行個體語言

## 傳回值

無。

## 功能

**結構描述：** [xtk:serverOptions](s-xtk-serveroptions.md)

**靜態：**

是
