# getUUID

產生唯一識別碼（通用唯一識別碼）。

```text
getUUID ()
```

## 參數

無。

## 傳回值

字元字串，包含&#39;550E8400-E29B-41D4-A716-446655440000&#39;型別的唯一識別碼。

**可用於：**

* 內容管理
* 傳遞屬性
* 類型規則
* JSSP
* SOAP方法
* WebApp
* 工作流程
