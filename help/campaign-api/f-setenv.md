# setEnv

>[!WARNING]
>
>此函式適用於內部部署環境。

>[!NOTE]
>
>您可以將&#x200B;**XtkSecurity\_Disable\_GetSetEnv**&#x200B;選項傳遞給&#x200B;**true**&#x200B;以停用此函式。

設定環境變數的值。

```text
setEnv (name, value)
```

## 參數

**名稱**&#x200B;環境變數的名稱。

**值**&#x200B;環境變數的新值。

## 傳回值

變數的新值。

## 功能

**可用於：**

* 內容管理
* 傳遞屬性
* 傳遞訊息
* 類型規則
* 匯入
* JSSP
* SOAP方法
* WebApp
* 工作流程
