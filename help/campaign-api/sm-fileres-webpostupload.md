# WebPostUpload

依據使用的儲存型別，在上傳（從網頁）至伺服器後最終確定資源的儲存。 復原程式碼頁和內容型別。

```text
fileRes.WebPostUpload ( XML params )
```

## 參數

**引數**&#x200B;對於&#39;workspace&#39;型別儲存： @formerFileName包含工作區中的先前名稱。 如果要立即儲存實體：@immediateSave必須設為「true」

## 傳回值

無。
