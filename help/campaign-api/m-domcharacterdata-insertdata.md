# 插入資料

將字元字串插入文字的特定位置。

```text
insertData (offset, arg)
```

## 參數

**offset**&#x200B;插入位置（第一個字元為0）。

**arg**&#x200B;要插入的字元字串。

## 傳回值

無。

## 功能

**類別的方法：** [DOMCharacterData](c-domcharacterdata.md)

**可用於：**

* 內容管理
* 傳遞屬性
* 傳遞訊息
* 類型規則
* 匯入
* JSSP
* SOAP方法
* WebApp
* 工作流程
