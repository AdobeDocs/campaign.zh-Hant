# SaveUrlInfo

將此傳遞的 URL 儲存為 URL 範本。

```text
SaveUrlInfo ( XML insUrlList, XML updUrlList )
```

## 參數

**insUrlList**&#x200B;新URL的清單（未與URL範本關聯）

**updUrlList**&#x200B;要更新的URL範本清單

## 傳回值

無。

**結構描述：** [nms:delivery](s-nms-delivery.md)

是
