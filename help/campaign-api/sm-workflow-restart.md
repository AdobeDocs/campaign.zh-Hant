# 重新啟動

將工作流程停止和工作流程開始連結在一起。

```text
Restart ( String workflowId )
```

## 參數

**workflowId**&#x200B;工作流程的識別碼或內部名稱。

## 傳回值

無。

**結構描述：** [xtk:workflow](s-xtk-workflow.md)

**靜態：**

是
