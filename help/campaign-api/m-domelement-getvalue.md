# getValue

傳回給定XPath參考的節點值。

```text
getValue (xpath)
```

## 參數

**xpath**&#x200B;路徑。

## 傳回值

參考之節點的文字值。

## 備註

XPath的語法只接受XPath語言子集。 如果路徑格式錯誤，則會引發例外狀況。

## 功能

**類別的方法：** [DOMElement](c-domelement.md)

**可用於：**

* 內容管理
* 傳遞屬性
* 傳遞訊息
* 類型規則
* 匯入
* JSSP
* SOAP方法
* WebApp
* 工作流程
