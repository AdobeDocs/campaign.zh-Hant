# fileRes

儲存在伺服器或資料庫上的檔案資源

## 方法

| 方法 | 說明 |
| --- | --- |
| [檔案發佈](sm-fileres-filepublishing.md) | 在前端伺服器上發佈公用資源。 |
| [GetPublicFileResURL](sm-fileres-getpublicfileresurl.md) | 取得資料夾 URL |
| [GetServerFileName](sm-fileres-getserverfilename.md) | 複製伺服器上的檔案後，如有必要，在上傳資料夾中傳回檔案名稱。 |
| [GetURL](sm-fileres-geturl.md) | 取得檔案 URL |
| [PostUpload](sm-fileres-postupload.md) | 上傳後處理，依據定義的儲存類型。 |
| [預先下載](sm-fileres-predownload.md) | 依據定義的儲存類型準備資源下載。 |
| [PublishIfNeeds](sm-fileres-publishifneeded.md) | 如有必要，複製媒體伺服器上的檔案 |
| [PublishIfNeededFromId](sm-fileres-publishifneededfromid.md) | 如有必要，使用資源 ID 複製媒體伺服器上的檔案 |
| [WebPostUpload](sm-fileres-webpostupload.md) | 依據使用的儲存型別，在上傳（從網頁）至伺服器後最終確定資源的儲存。 復原程式碼頁和內容型別。 |
