# 資料保護：逸出功能

Adobe Campaign提供一組功能，可針對最常見的攻擊提供保護：SQL插入、XSS攻擊等。

逸出功能應在營運商的監督下使用，Adobe可能對開發期間不當使用或缺少使用這些功能概不負責。

一般規則如下：

**所有引數都必須逸出。 用於逸出的函式取決於資料的目的地格式。**

## 簡化的逸出

在JSSP中，Adobe Campaign提供「&lt;%=」標籤，可讓您逸出產生的XML或HTML實體中使用的變數。 此方法更方便，相當於NL.XML.escape()。 以下範例說明如何使用標籤來逸出引數：

```xml
<li>
<%= strRecipientList %>
</li>
```

## 進階逸出：

Adobe Campaign提供4個函式，可讓您根據目的地格式逸出引數。若要存取這些逸出函式，請分別命名下列檔案：

```javascript
NL.require('/nl/core/shared/xml.js')
NL.require('/nl/core/sql.js')
NL.require('/nl/core/shared/xtk.js')
NL.require('/nl/core/shared/js.js')
```

* NL.XML.escape(data)，用於逸出產生的XML或HTML實體中使用的變數。 此函式等同於&#39;&lt;%=&#39;語法。 此函式在NL.XML封裝中定義。

  ```xml
  <tr>
  <td><%==NL.XML.escape(node.id)%><td>
  <td><%==NL.XML.escape(node.label)%><td>
  </tr>
  ```

* NL.SQL.escape(data)以逸出可用於SQL查詢的引數。 此函式自動將運算式放置在簡單引號之間。 此函式在NL.SQL封裝中定義。

  ```javascript
            var strSql = "UPDATE NmsRecipient SET sEmail="+NL.SQL.escape(strEmail)+ " WHERE ...";
  ```

* NL.XTK.toXTKString(data)可逸出預計用於XTK運算式的引數。 此函式在NL.XTK套件中定義。

  ```javascript
  var query = NLWS.xtkQueryDef.create(
    {queryDef: {schema: "nms:recipient", operation: "select", 
      select: {
        node: [
          {expr: "@firstName"}, 
          {expr: "@lastName"} 
        ]
      }, 
      where: {
        condition: {expr: "@email=" + NL.XTK.toXTKString(request.getParameter("query"))}
      }
    }})
  ```

* NL.JS.escape(data)可逸出用於使用者端執行的javascript中的變數。 此函式在NL.JS套件中定義。

  ```xml
  <script type="text/javascript">
                var value = “Foo <%== NL.JS.escape(Node.@value) %>”; 
  </script>
  ```

警告： Adobe Campaign無法保證這些函式在較新版本中的耐久性。
