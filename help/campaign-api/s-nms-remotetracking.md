# remoteTracking

遠端追蹤管理服務的存取權

## 方法

| 方法 | 說明 |
| --- | --- |
| [CreateInstance](sm-remotetracking-createinstance.md) | 用於建立追蹤執行個體 |
| [CreateInstanceEx](sm-remotetracking-createinstanceex.md) | 用於建立追蹤執行個體 |
| [GetTrackingInfo](sm-remotetracking-gettrackinginfo.md) | 允許遠端重新導向伺服器下載有關傳遞動作的資訊。 |
| [GetTrackingLogs](sm-remotetracking-gettrackinglogs.md) | 使您能夠收集重新導向和網路追蹤服務產生的追蹤記錄。 |
| [GetTrackingLogs4](sm-remotetracking-gettrackinglogs4.md) | 允許使用 Post 4.00 格式，檢索由遠端重新導向和網路追蹤伺服器產生的追蹤記錄。 |
| [PushRelayInfo](sm-remotetracking-pushrelayinfo.md) | 可讓您將有關傳遞的資訊上傳到遠端追蹤伺服器。 |
| [PushTrackingInfo](sm-remotetracking-pushtrackinginfo.md) | 允許在遠端追蹤伺服器上傳有關傳遞的所有資訊 |
| [RegisterInstance](sm-remotetracking-registerinstance.md) | 用於核准追蹤執行個體 |
