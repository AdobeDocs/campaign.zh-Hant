# fileSize

傳回檔案大小（位元組）。

```text
fileSize (filename)
```

## 參數

**檔案名稱**&#x200B;檔案的全名。

## 傳回值

傳回檔案大小，或如果發生錯誤（例如，如果找不到檔案）則傳回–1。

## 功能

**可用於：**

* 內容管理
* 傳遞屬性
* 類型規則
* JSSP
* SOAP方法
* WebApp
* 工作流程
