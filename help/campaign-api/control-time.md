# 時間

時間型別控制項可讓您輸入一天中的時間。

![時間控制項](assets/time.0ff42b85.png)

## 屬性

**backColor — 字串**&#x200B;背景顏色（btnshasow，白色）。

**邊框 — 字串**&#x200B;變更控制項的邊框樣式（實線、雙線、內縮、外凸、無）。

**font-size - integer**&#x200B;變更字型大小。

**標籤 — 字串**&#x200B;關聯的標籤。

**nolabel — 布林值**&#x200B;隱藏關聯的標籤。

**readOnly — 布林值**&#x200B;強制控制項為唯讀。

**必要 — 布林值**&#x200B;欄位是必要的。
