# 檔案重新命名

變更檔案的名稱。

如果未指定字元編碼，則會使用伺服器預設值。

```text
fileRename (oldname, newname)
```

## 參數

**oldname**&#x200B;要重新命名的檔案完整名稱。

**newname**&#x200B;檔案的新名稱。

## 傳回值

無。

## 功能

**可用於：**

* 內容管理
* 傳遞屬性
* 類型規則
* JSSP
* SOAP方法
* WebApp
* 工作流程
