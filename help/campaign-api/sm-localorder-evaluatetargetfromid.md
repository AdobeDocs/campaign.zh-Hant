# EvaluateTargetFromId

評估連結至訂單的每個行銷活動傳遞的行銷活動目標定位。 這項評估將在使用操作員許可權訂購時以及建立本機行銷活動之前執行。

```text
XML result = EvaluateTargetFromId ( Number orderId )
```

## 參數

**orderId**&#x200B;訂單識別碼。

## 傳回值

**結果**&#x200B;每個行銷活動傳遞的計數結果。

## 功能

**結構描述：** [nms:localOrder](s-nms-localorder.md)

**靜態：**

是
