# addHeader

在回應中新增其他HTTP標頭。

```text
addHeader (nom, valeur)
```

## 參數

**nom**&#x200B;要新增的標頭名稱。

已新增標頭的&#x200B;**valeur**&#x200B;值。

## 傳回值

無。

## 功能

**類別的方法：** [HttpServletResponse](c-httpservletresponse.md)

**可用於：**

* JSSP
* WebApp
