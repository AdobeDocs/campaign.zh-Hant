# 處置

釋放物件使用的資源。

```text
dispose ()
```

## 參數

無。

## 傳回值

無。

## 備註

此方法可用來釋放物件所使用的資源，而不需等待記憶體回收行程或指令碼結束完成物件。

## 功能

**類別的方法：** [MemoryBuffer](c-memorybuffer.md)

**可用於：**

* 內容管理
* 傳遞屬性
* 傳遞訊息
* 類型規則
* 匯入
* JSSP
* SOAP方法
* WebApp
* 工作流程
