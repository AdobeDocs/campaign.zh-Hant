# MoveNode

在導覽樹狀結構中移動資料夾

```text
MoveNode ( String key, String parentKey, Number order, String fullName )
```

## 參數

**索引鍵**&#x200B;節點索引鍵

**parentKey**&#x200B;父索引鍵

**訂單**&#x200B;新節點索引

**fullName**&#x200B;完整名稱（不為空白以變更樹狀結構中的父系）

## 傳回值

無。
