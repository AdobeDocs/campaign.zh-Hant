# CreateOperationFromModelId

從行銷活動範本中建立行銷活動。

```text
Number operationId = CreateOperationFromModelId ( Number modelId, XML operationPlanning )
```

## 參數

行銷活動範本的&#x200B;**modelId**&#x200B;識別碼

**operationPlanning**&#x200B;促銷活動排程

## 傳回值

已建立執行個體的&#x200B;**operationId**&#x200B;識別碼
