# EvaluateTarget

評估連結至訂單的每個行銷活動傳遞的行銷活動目標定位。 這項評估將在使用操作員許可權訂購時以及建立本機行銷活動之前執行。

```text
XML result = EvaluateTarget ( XML order )
```

## 參數

包含訂單資訊的&#x200B;**訂單**&#x200B;專案。

## 傳回值

**結果**&#x200B;每個行銷活動傳遞的計數結果。
