# getElementById

傳回具有指定ID的元素。

```text
getElementById (elementId)
```

## 參數

**elementId**&#x200B;搜尋專案的識別碼。 字元字串需大幅區分大小寫。

## 傳回值

元素；如果檔案不包含具有特定ID的元素，則為null。

## 功能

**類別的方法：** [DOMDocument](c-domdocument.md)

**可用於：**

* 內容管理
* 傳遞屬性
* 傳遞訊息
* 類型規則
* 匯入
* JSSP
* SOAP方法
* WebApp
* 工作流程
