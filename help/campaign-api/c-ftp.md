# FTP （類別）

FTP物件可讓您使用FTP通訊協定執行許多操作。

## 方法

| 方法 | 說明 |
| --- | --- |
| [FTP](m-ftp-ftp.md) | 建立新物件以執行FTP命令。 |
| [處置](m-ftp-dispose.md) | 釋放物件使用的資源。 |
| [清單](m-ftp-list.md) | 傳回伺服器上指定目錄中的檔案清單。 |
| [下載](m-ftp-download.md) | 將檔案從伺服器下載至本機檔案或記憶體。 |
| [上傳](m-ftp-upload.md) | 從本機檔案下載檔案至FTP伺服器。 |
| [setFile](m-ftp-setfile.md) | 定義傳輸模式和接收檔案。 |

## 功能

**可用於：**

* 內容管理
* 傳遞屬性
* 類型規則
* JSSP
* SOAP方法
* WebApp
* 工作流程
