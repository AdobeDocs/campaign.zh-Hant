導覽階層中的資料夾

## 方法

| 方法 | 說明 |
| --- | --- |
| [CheckEntityWriteRight](sm-folder-checkentitywriteright.md) | 如果目前的操作者擁有給定實體的寫入權限，則傳回「真」 |
| [DropSelection](sm-folder-dropselection.md) | 將選擇移動到導覽樹狀資料夾中 |
| [FindFirstAuthorized](sm-folder-findfirstauthorized.md) | 為目前使用者尋找滿足 folderFilter 條件的第一個合格資料夾。 |
| [HasFolderWriteRight](sm-folder-hasfolderwriteright.md) | 如果可寫入資料夾，則傳回「真」 |
| [InheritParentFolderRights](sm-folder-inheritparentfolderrights.md) | 使用父資料夾權限來更新資料夾實體 |
| [LoadChildren](sm-folder-loadchildren.md) | 載入給定節點的子系清單 |
| [LoadChildrenWithPath](sm-folder-loadchildrenwithpath.md) | 載入給定節點的子系清單 |
| [移動節點](sm-folder-movenode.md) | 在導覽樹狀結構中移動資料夾 |
| [MoveSelection](sm-folder-moveselection.md) | 將選擇移動到導覽樹狀資料夾中 |
| [新資料夾](sm-folder-newfolder.md) | 建立資料夾 |
